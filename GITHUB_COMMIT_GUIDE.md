# Suggested Git Commit Sequence

Use separate commits when the work is naturally separated. If all changes are already complete, one accurate commit is better than inventing a history.

1. `Apply lecturer feedback to image sizing`
2. `Add JavaScript service filtering and sorting`
3. `Add FAQ accordion and gallery lightbox`
4. `Add interactive service area map`
5. `Add page-specific SEO metadata and crawler files`
6. `Add validated asynchronous enquiry and contact forms`
7. `Improve image loading and add final QA documentation`

Only use commit dates and messages that accurately reflect when the work was done.
