# Part 3 Phase 3 Test Checklist

Record the date, browser and result for each test. Do not mark a test as passed until you have performed it.

- [ ] Open each page and confirm its browser tab title is unique.
- [ ] Inspect page source and confirm each page has a meta description and canonical URL.
- [ ] Open `/robots.txt` and `/sitemap.xml` on the deployed website.
- [ ] Submit each form empty and confirm required-field validation appears.
- [ ] Enter an invalid email address and confirm validation blocks submission.
- [ ] Enter an invalid phone number in the project enquiry form and confirm validation blocks submission.
- [ ] Enter text below the minimum length and confirm validation blocks submission.
- [ ] Submit a test message using an email address you control, after the recipient has verified FormSubmit.
- [ ] Confirm the success message appears only after a successful service response.
- [ ] Test failed/offline submission and confirm a helpful error message appears.
- [ ] Repeat form layout checks on desktop and mobile.

**Important:** Form delivery depends on the recipient verifying the first FormSubmit confirmation email. Confirm the recipient address is authorised before publishing.
